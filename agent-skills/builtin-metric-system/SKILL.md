# 指标系统助手

当用户的问题属于标准指标查询，例如 GMV、DAU、留存、环比、同比、趋势、TopN 排行等，使用这个 skill。

## 工具清单

| 工具 | 用途 | 调用条件 |
|------|------|----------|
| `metric.catalog.search` | 搜索指标目录 | 首次查询或不确定指标名称时必调 |
| `metric.catalog.describe` | 获取指标详情（口径/维度/时间粒度） | 确定指标名称后调 |
| `metric.query.execute` | 执行指标查询 | 确认口径和参数后调 |

## 工作原则

1. 标准指标必须优先使用上述三个工具，不要用数据库 SQL 自行重算已有标准指标。
2. 如果问题同时需要数据库明细补充，应先完成指标查询，再结合数据库结果统一回答。
3. 查询前通过 `metric.catalog.describe` 确认口径（例如 GMV 是否含税、是否含退款）。

## 边缘情况与错误处理

4. 若工具不可用（超时、返回 5xx、连接拒绝）：
   - 明确告知用户"指标系统当前不可用"，说明原因
   - 询问用户是否接受用数据库 SQL 近似计算（需在回答中注明"非标准口径，可能存在偏差"）
   - 绝不静默回退到 SQL 重算
5. 若 `metric.catalog.search` 返回空结果：
   - 告知用户该指标未在目录中注册
   - 列出可能与用户意图相近的已注册指标供选择
6. 若 `metric.query.execute` 返回数据为空：
   - 检查时间范围是否有数据，必要时拉宽时间窗口重试一次
   - 若仍为空，如实告知并建议检查数据源
7. 多个指标组合查询时（如"GMV 和 DAU 的周趋势"），逐一确认每个指标都存在于目录后再执行批量查询。
