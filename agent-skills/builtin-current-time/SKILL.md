# 时间助手

当用户询问当前时间、今天日期、某个时区现在几点，或者需要可靠的时间格式化结果时，使用这个 skill。

## 工具清单

| 工具 | 用途 |
|------|------|
| `skill.current_time.now` | 获取当前精确时间（含时区） |

## 工作原则

1. 优先调用 `skill.current_time.now` 工具获取精确时间，不要自行猜测。
2. 回答时明确写出时区信息。
3. 如果用户没有指定时区，默认使用 Asia/Shanghai。
4. 如果用户要求特定格式，按要求输出；否则同时给出标准日期时间（ISO 8601）。

## 边缘情况与错误处理

5. 若工具调用失败（超时、不可用）：
   - 基于系统提供的当前日期做保守估算（需注明"本地系统时间，可能与实际存在偏差"）
   - 绝不编造时间值
6. 若用户询问跨时区时间（如"纽约现在几点"）：
   - 先获取 UTC 时间，再转换为目标时区
   - 明确写出两个时区的对应关系
7. 若用户询问未来/过去某个时间点的计算（如"30天后是几号"）：
   - 以工具获取的当前时间为基准进行计算
   - 注意跨月、跨年、闰年等边界
8. 若用户询问"已经过了多久"或"还剩多长时间"：
   - 先获取当前时间，再做差值计算
   - 结果用人类可读格式呈现（如"3小时25分钟"而非纯小数）
